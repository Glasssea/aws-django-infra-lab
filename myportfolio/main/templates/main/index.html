AWS EC2 (Ubuntu) 위에서 직접 구성한 배포 구조

AWS EC2 Ubuntu Nginx Gunicorn Django MySQL systemd
  • Security Group으로 SSH(22) / HTTP(80) 접근을 관리했습니다.
  • Gunicorn을 systemd 서비스로 등록해 애플리케이션이 상시 구동되도록 했습니다.
  • Elastic IP로 고정 Public IP를 구성했습니다.
  • Nginx static 403 오류를 로그로 원인을 좁혀 디렉토리 권한 문제로 해결했습니다.
