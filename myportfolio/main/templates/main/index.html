FEATURED INFRASTRUCTURE PROJECT

이 포트폴리오 사이트를 직접 구축한 AWS 인프라

지금 보고 계신 이 사이트는 AWS EC2 + Ubuntu 위에 직접 구성한 서버 환경에서
Nginx · Gunicorn · Django · MySQL로 서비스되고 있습니다.

EC2 t3.micro Ubuntu 24.04 1 GiB RAM 2GB Swap File MySQL 8.0 Gunicorn systemd Nginx Unix Socket Elastic IP Security Group

Architecture

Client → Nginx → Gunicorn (Unix Socket) → Django → MySQL 8.0

Deployment Flow

EC2 → Ubuntu → Swap → MySQL → Gunicorn + systemd → Nginx → Elastic IP / Security Group → LIVE
  • t3.micro(1GiB RAM)의 제한된 메모리를 보완하기 위해 EBS 저장공간을 활용한 2GB Swap File을 직접 구성했습니다.
  • Nginx static 403 오류를 로그로 원인을 좁혀 Linux 디렉토리 권한 문제로 확인하고 해결했습니다.
