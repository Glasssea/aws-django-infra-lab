안녕하세요, 윤성찬입니다.

Python을 기반으로 웹 제작부터 배포능력을 갖춘 개발자입니다.

이 웹 사이트는 AWS EC2 서버를 구축하여 Python Django를 사용하여 제작하였고,

AWS는 독학하여 IAM Identify Center를 다룰 수 있고, EC2의 보안설정을 사용할 수 있습니다.

배포를 위해 Gunicorn을 애플리케이션 서버로 사용하였고, Nginx를 리버스 프록시 서버로 설정였습니다.

포트폴리오 하나에 이렇게 AWS와 도메인비용을 내고 있는 것이 비효율적이라 생각하시겠지만
이것도 저것도 잘 할 수 있다는 것을 보여드리고 싶었습니다.

보안을 위해 Let's Encrypt의 Certbot을 사용하여 무료 SSL 인증서를 발급받아 적용시켰습니다.
