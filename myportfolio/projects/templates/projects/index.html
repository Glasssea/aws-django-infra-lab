TrollBatta

Riot API를 활용한 League of Legends 전적 검색 서비스입니다.
Riot ID와 태그를 입력하면 최근 게임 전적과
챔피언, KDA, 아이템 등의 정보를 확인할 수 있습니다.

기존 Django 기반 프로젝트에서 시작하여
Riot API의 변경사항과 최신 시즌 데이터를 반영하면서
별도의 웹 서비스로 개선하였습니다.

주요 기능 :
Riot ID 기반 소환사 검색
최근 20게임 전적 조회
솔로랭크 / 자유랭크 정보 조회
챔피언, KDA, 아이템 정보 표시
최신 Data Dragon 데이터 적용

TrollBatta 바로가기

기억의 미로(team project)

수정중 : 랭킹의 순위가 제대로 반영되지 않는 부분

게임 설명 :
제한 시간 안에 보이지 않는 지뢰를 피해 목적지에 도달하는 게임
캐릭터를 꾸밀 수 있도록 하여 사용자에게 흥미를 더함
제한시간을 둬 긴장감을 더함
랜덤 아이템을 배치해 사용자가 운적 요소를 느끼게 함
로컬스토리지를 이용하여 랭킹을 표시하였음.

파스쿠찌

내용 : 리디자인
디자인 기획 :
1. 배경의 단조로움 해결
기획 : 파스쿠찌의 깨끗하고 쾌적한 매장 사진 배치
기대효과 : 사용자가 매장의 분위기를 느껴 방문하고 싶은 마음이 들게 함

2. 파스쿠찌의 메인 에스프레소
기획 : 파스쿠찌만의 자랑 에스프레소를 설명하는 내용 추가
기대효과 : 사용자로하여금 파스쿠찌의 에스프레소에 특별함을 느끼게 함

도미노피자

내용 : 리디자인

1. 상단 메뉴바의 불안정한 움직임 조율
기획 : 상단 메뉴바의 불안정한 움직임 부드럽게 바꿈

2. 하단 요소들의 재배치
기획 : 하단 요소들을 블록이 쌓여있는 듯 한 모습으로 배열
도미노 피자의 로고 색상을 메뉴에 적용
맛있어 보이는 피자 메뉴 번갈아가며 노출
기대효과 : 웹 방문시 사용자가 피자를 먹고 싶다는 생각이 들게 함
도미노 로고와 비슷한 색상을 보여주어 무의식 중에 로고가 각인되게함

3. 기능 javascript를 이용하여 뉴스가 자동으로 넘어가고,
사용자가 원할 시 클릭을 이용하여 넘길 수 있음.
