FEATURED PROJECT

AWS Django Infrastructure Deployment

Problem

기존 Django 프로젝트를 실제 AWS 환경에서 직접 운영해보며
서버와 네트워크 인프라를 이해하고 싶었습니다.

Architecture

Client → Nginx → Gunicorn → Django → MySQL

AWS EC2 (Ubuntu)

AWS Nginx Gunicorn Django MySQL

What I Did

  • AWS EC2 Ubuntu 인스턴스 구성
  • Security Group으로 SSH(22) / HTTP(80) 접근 제어
  • Nginx를 Reverse Proxy로 구성
  • Gunicorn을 systemd 서비스로 등록하여 Django 애플리케이션 실행
  • Unix Socket을 통해 Nginx와 Gunicorn 연동
  • MySQL 데이터베이스 구성 및 Django 연결
  • Elastic IP를 사용하여 고정 Public IP 구성

Troubleshooting

Nginx에서 static 파일을 제공하도록 설정한 뒤 403 Forbidden 오류가 발생했습니다.
로그를 확인한 결과 Nginx 실행 사용자(www-data)가 /home/ubuntu 디렉토리를 통과할 권한이 없었고,
디렉토리 권한을 조정하여 static 파일이 정상적으로 제공되도록 해결했습니다.

TrollBatta 바로가기

챔피언 추천 시스템 (SVD)

TrollBatta의 소환사 검색 결과 화면에 연결되어 있는 추천 시스템입니다.

How It Works

  • Riot API로 소환사의 챔피언 숙련도(Champion Mastery) 데이터를 수집합니다.
  • Pandas로 데이터를 사용자 × 챔피언 pivot 테이블 형태로 가공합니다.
  • scikit-learn의 TruncatedSVD로 차원을 축소한 뒤 복원(inverse_transform)하여, 적게 플레이했지만 예측 선호도가 높은 챔피언을 찾습니다.
  • 검색 결과 화면에 추천 챔피언 3개를 노출합니다.
Python Pandas scikit-learn SVD

관련 코드 : common/mastery_SVD.py, search/views.py
