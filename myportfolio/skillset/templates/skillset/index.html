Infrastructure · Development · Data & AI

Linux, AWS 기반 서버 인프라 구축 경험과
Python, Django 기반 웹 개발 경험을 함께 갖추고 있습니다.
Nginx, Gunicorn, systemd로 서비스를 직접 배포·운영해보았고,
MySQL / MariaDB로 데이터베이스를 다룰 수 있습니다.
Pandas, scikit-learn을 활용한 추천 시스템 개발 경험이 있으며,
Git으로 협업 및 버전 관리를 진행합니다.

Infrastructure & Deployment


AWS EC2(Ubuntu) 환경에 Django 서비스를 직접 배포했습니다.
Nginx를 리버스 프록시로, Gunicorn을 WSGI 서버로 구성했고,
Gunicorn은 systemd 서비스로 등록해 상시 구동되도록 했습니다.
Security Group으로 접근을 관리하고 Elastic IP로 고정 IP를 구성했습니다.

Data & AI


Python 기반 Pandas로 데이터를 가공하고
scikit-learn(TruncatedSVD)을 이용해 추천 시스템을 구현한 경험이 있습니다.
관련 내용은 TrollBatta 프로젝트의 챔피언 추천 기능에서 확인할 수 있습니다.

Recommendation System


Riot API로 수집한 챔피언 숙련도 데이터를 pivot 테이블로 구성하고,
SVD로 차원을 축소했다가 복원해 선호할 가능성이 높은 챔피언을 예측합니다.
TrollBatta의 소환사 검색 결과 화면에 추천 챔피언 3개를 노출합니다.
